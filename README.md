# Software-Automation-CS320
# How can I ensure that my code, program, or software is functional and secure?
To help ensure that the software I make is functional is by testing the program against the requirements. For the assignments in this class I used JUnit tests to validate valid and invalid conditions, null values and specific requirements for the specified fields in the requirements. To help assess security, I reviewed my code for potential issues. This assignment did not use real sensitive data, so protections for storing sensitive information is not required. To validate functionality passing tests provide confidence of behavior but additional testing is required if the standalone program is integrated to a larger system.
# How do I interpret user needs and incorporate them into a program?
I interpret user needs by reviewing the requirements and converting them into methods or functions that can be implemented and tested. For example, the contact assignment defined character limits, and required fields. I incorporated these in the functions and created tests around the requirements to validate the code.  
# How do I approach designing software?
I approach designing software by understanding what is needed. Designing software should solve a problem improve efficiency and provide a service. If working from a set of requirements, turning those requirements into small and actionable tasks is a great place to start. Making code around easy to understand methods and functions, this creates robust, scalable code that can be easier to debug and maintain.
